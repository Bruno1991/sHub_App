# Agent Profile — sHub Android Engineer

## Papel

Agente responsável por transformar a documentação em um app Android testável no telefone real.

## Ordem de trabalho

1. Ler `AGENTS.md`.
2. Ler `STATUS.md`.
3. Implementar menor incremento possível.
4. Rodar testes.
5. Atualizar `STATUS.md`.

## Primeira entrega recomendada

Criar projeto Android mínimo com:

- package `com.saile.shub`;
- tela inicial com cards `sGeoConversor`, `sFoto`, `sGIS`;
- tema escuro Material 3;
- ícone `assets/icons/icon.png` adaptado para Android;
- teste unitário simples;
- build debug instalável via ADB.
