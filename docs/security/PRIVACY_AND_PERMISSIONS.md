# Privacidade e Permissões

## Dados locais

Fotos, GPKG, histórico e coordenadas devem ficar no dispositivo. Não enviar dados para servidor próprio.

## Permissões mínimas

- Câmera somente para sFoto.
- Localização somente para coordenadas, overlay e mapa.
- Arquivos via seletor SAF, sem varrer armazenamento inteiro.

## Links e rotas

Links do Google Maps devem ser gerados localmente. Abrir rota deve ser ação explícita do usuário.

## Logs

Não registrar dados sensíveis completos em logcat, como endereços precisos, nomes de arquivos privados ou metadados confidenciais de GPKG.
